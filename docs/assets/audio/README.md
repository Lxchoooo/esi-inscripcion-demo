# Música de la presentación

## `promo.mp3`

Mezcla de dos canciones provistas por el responsable del proyecto:

- "No Me Olvides", de Abel Pintos.
- "Brindis", de Soledad.

La primera suena hasta los 2:52, donde termina el puente y cambia la sección
(no es el medio de un estribillo). Ahí se cruza durante 8 segundos con la
segunda, que entra desde el principio y suena completa. Cuando termina la
mezcla, vuelve a empezar. Dura 7:28.

- Crossfade equal-power de 8 s.
- La primera se empareja en volumen con una rampa suave de -3 dB entre 2:20 y
  2:52; el master queda en -1 dB para evitar clipping.

- Está recodificada a 96 kbps estéreo y 44,1 kHz para reducir el peso.
- Suena desde la diapositiva "Palabras para la promo" hasta la última, y se
  puede silenciar o volver a activar con el botón de música.
- No se precachea: se descarga solo cuando se reproduce.
